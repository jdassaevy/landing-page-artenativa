# Arte Nativa

Novo site institucional e painel administrativo da Arte Nativa.

## Stack

Next.js 16, React 19, TypeScript, Tailwind CSS v4, Motion e Supabase.

## Desenvolvimento

```bash
corepack enable
pnpm install
pnpm dev
```

## Qualidade

```bash
pnpm lint
pnpm vitest run
pnpm build
```

A arquitetura e o plano de implementação ficam em `docs/superpowers/`.
